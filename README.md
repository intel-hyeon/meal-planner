## 1. 제작한 것 소개

매주 식단을 계획하고 마트에 가기 전 장보기 목록을 정리하는 20대 대학생 및 1인 가구를 위한 웹 앱입니다.

### 현재 구현된 주요 기능 (1~2단계 완료 시점)
- **레시피 동적 CRUD:** 재료명(20자 제한), 수량(양의 실수), 단위(10자 제한) 입력 폼 제공
- **동적 행 추가/삭제:** `+` 버튼으로 재료 칸 동적 추가 (최대 100개 상한 제한), `-` 버튼으로 해당 칸 즉시 삭제
- **기준 인분 수(N) 설정:** 레시피별로 기준 인분 수를 지정할 수 있는 입력 폼 제공
- **빈칸 자동 정제 (Cleanup):** 재료 입력란 중 내용이 없는 공란 행은 저장 시 자동으로 걸러져 화면과 로컬 캐시에서 완전 증발
- **로컬 캐시 영속화:** `localStorage`를 통해 브라우저 새로고침(F5) 후에도 작성한 레시피가 안전하게 보존

## 3. Todo 리스트의 변경 내역 (피드백 반영)

2단계 완료 후 사용자가 브라우저에서 직접 테스트하며 전달한 피드백을 수렴하여 초기 계획에서 아래 내용을 변경했습니다:

| 구분 | 초기 계획 (v0) | 사용자 피드백 반영 (v1) | 변경 이유 및 근거 |
|---|---|---|---|
| **프로젝트 타이틀** | `주간 식단 플래너 & 장바구니` | `식단 플래너 & 장바구니` | 간결하고 직관적인 서비스 명칭으로 간소화 요청 |
| **플레이스홀더 예시** | `예: 백종원 김치찌개, 된장찌개` | `예: 김치찌개, 된장찌개` | 특정 인명 등 부가적인 수식어 배제 요청 |
| **모달 상단 중복 문구** | `저장 시 내용이 없는 빈칸 행은 자동으로 정리(증발)됩니다.` 노출 | 모달 헤더 문장 제거 | 하단의 *"💡 입력하지 않고 남겨둔 빈 재료 칸은..."* 안내와 한 화면에서 중복 서술되므로 제거 |
| **레시피 탭 상단 문구** | `레시피를 등록하면 빈칸은 자동으로 정리되며...` 노출 | 문장 완전 제거 | 화면을 군더더기 없이 깔끔하게 유지하기 위해 제거 |
| **장바구니 탭 문구** | `장바구니 및 비례 계산 목록`, `(M)인분` 노출 | `장바구니`, `(M)` 표기 제거 | 타이틀 간소화 및 직관적 사용자 경험 제공 |

## 4. 사용한 스킬

본 프로젝트에서는 복잡한 식재료 비례 연산과 단위 일치 규칙, 로컬 스토리지 무결성을 검증하기 위해 **`meal-planner-qa`** 스킬 절차를 준수하며 개발하고 있습니다.

- **스킬 목적:** 소수점 셋째 자리 버림 규칙 준수, 동일 재료명-단위 완전 일치 그룹화, 로컬스토리지 고아 데이터 방지
- **작업 방식:** AI 에이전트가 각 단계 코드를 구현한 후 빌드 검증 및 엣지 케이스를 자가 점검하고 사용자에게 보고하는 표준 절차로 활용합니다.

---

## 5. 느낀점 및 결론

- **계획과 화면의 분리:** 화면 인터랙션을 먼저 만들고 세부 데이터 로직을 연결하는 방식을 취하니, 입력 제약이나 행 동적 추가 같은 사용자 경험을 조기에 검증할 수 있었습니다.
- **피드백 루프의 중요성:** AI가 작성한 문구에 중복이 있거나 예시가 다소 길어지는 경향이 있었는데, 사용자가 직접 화면을 보고 "중복 문구 제거", "타이틀 간소화"와 같은 피드백을 전달하여 코드가 빠르게 정제되는 바이브 코딩의 시너지를 경험했습니다.

## 6. 실행 방법

```bash
# 의존성 설치
npm install

npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하여 실행할 수 있습니다.
