# Meal Planner QA Skill

이 스킬은 **'식단 플래너 & 장바구니'** 프로젝트를 바이브 코딩으로 개발할 때, AI 에이전트가 비즈니스 로직의 정확성과 데이터 무결성을 보장하기 위해 준수해야 하는 검증 절차와 지침을 정의합니다.

---

## 1. 스킬을 만든 이유

레시피 기반 식재료 계산 앱은 단순한 CRUD와 달리 다음과 같은 까다로운 요구사항이 존재합니다:
1. **부동소수점 오차 및 절삭 규칙:** 자바스크립트의 IEEE 754 부동소수점 연산 특성으로 인해 `0.1 + 0.2 = 0.30000000000000004` 같은 연산 오차가 발생할 수 있으며, "소수점 셋째 자리 버림"을 정확히 구현하지 않으면 `1.33333...` 또는 `1.6666...` 같은 무한소수가 장보기 목록에 그대로 노출됩니다.
2. **단위 혼동 방지 (가장 중요한 페르소나 불편점):** 동일한 '양파'라도 '개'와 'g'가 억지로 합산되면 요리 시 치명적인 계량 오류가 발생합니다.
3. **로컬 캐시 고아(Orphan) 데이터 방지:** 백엔드 없이 `localStorage`로만 상태를 관리할 때, 원본 레시피 삭제 시 장바구니 쪽에 유령 데이터나 `null`이 남지 않도록 무결성을 엄격히 통제해야 합니다.

이러한 규칙들을 매 프롬프트마다 반복 설명하지 않고, AI 에이전트가 코드를 작성하거나 수정할 때 자동으로 이 절차를 따르도록 하기 위해 이 스킬을 제작했습니다.

---

## 2. 핵심 검증 규칙 (Core Rules)

### 규칙 1: 인분 수 비례 계산 및 소수점 셋째 자리 버림
- **계산 공식:** `필요 수량 = 기존 양 * (목표 인분 M / 기준 인분 N)`
- **버림(Floor) 원칙:**
  - 계산 결과에서 소수점 셋째 자리 숫자를 버림(내림) 처리하여 둘째 자리까지만 유효하게 남깁니다.
  - 부동소수점 연산 오차 방지를 위해 `1e-9` 보정 또는 `toFixed(6)` 후 `Math.floor` 절삭을 적용합니다.
  - 정수인 경우 소수점을 붙이지 않고 정수로 출력합니다 (`2.00` → `2`).

### 규칙 2: 재료명 + 단위 완전 일치 합산 (Exact Match Aggregation)
- 장바구니 내 전체 레시피의 재료를 순회하여 합산할 때의 고유 키는 반드시 **`${재료명}____${단위}`** 형태여야 합니다.
- **검증 케이스:**
  - `대파 0.5 대` + `대파 0.5 대` → `대파 1 대` (합산 대상)
  - `고기 200 g` + `고기 1 근` → `고기 200 g`, `고기 1 근` (단위가 다르므로 반드시 개별 행으로 분리)

### 규칙 3: 가나다순 자동 정렬
- 합산된 목록은 반드시 한국어 로케일(`localeCompare('ko')`)을 기준으로 가나다순 정렬되어야 합니다.

### 규칙 4: 레시피 삭제 시 장바구니 무결성 동기화
- 원본 레시피가 삭제되면:
  1. `recipes` 배열에서 해당 레시피 제거
  2. `cart` 배열에서 해당 `recipeId`를 가진 모든 항목 제거
  3. 로컬 스토리지 키(`meal_organizer_recipes_v1`, `meal_organizer_cart_v1`)에 동기화 반영
  4. 고아 데이터 방어: 레시피 목록에 존재하지 않는 ID가 장바구니에 남아있을 경우 자동 감지하여 즉시 소멸

### 규칙 5: 텍스트 클립보드 출력 포맷
- 클립보드에 복사되는 텍스트는 모바일 메신저(카카오톡)나 메모장에 바로 붙여넣어 장을 볼 수 있도록 아래 표준 규격을 유지합니다:
  ```text
  [장보기 목록]
  - {재료명}: {수량} {단위}
  ```

---

## 3. 에이전트 작업 절차

1. **코드 변경 전:** 위 5가지 핵심 규칙을 침해하는 변경이 있는지 사전 검토한다.
2. **코드 변경 후:**
   - `npm run build`를 실행하여 TypeScript 타입 오류 및 빌드 무결성을 검사한다.
   - 엣지 케이스(재료 칸 빈칸 저장, 음수 입력 시도, 최대 100개 초과, 소수점 나눗셈)를 브라우저 환경에서 점검한다.
3. **보고 시:** 완료한 작업 번호와 함께 사용자가 직접 브라우저에서 검증할 수 있는 재현 절차를 안내한다.
